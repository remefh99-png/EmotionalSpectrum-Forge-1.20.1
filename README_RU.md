# Emotional Spectrum: Beyond Willpower — Forge 1.20.1

Исходный проект версии 0.5.0. Готовый `.jar` можно получить автоматически через GitHub Actions: после загрузки проекта в GitHub открой вкладку **Actions**, выбери последний успешный запуск **Build Minecraft mod**, затем скачай артефакт `emotional-spectrum-forge-1.20.1` внизу страницы запуска.

## Реализовано
- Девять колец эмоционального спектрума с предметами, моделями и текстурами.
- Curios-слот `ring` на 9 позиций; кольца не складываются.
- Одновременное ношение нескольких цветов.
- Отдельный резерв энергии для каждого цвета: +1000 максимума за кольцо.
- Регенерация 10 энергии в секунду.
- Девять базовых эффектов корпуса по клавише V.
- Цветной энергетический луч по клавише C: 24 блока, 150 энергии, частицы соответствующего цвета и урон цели.
- Полёт по клавише B в режиме выживания; снимаешь все кольца — полёт отключается.
- Переключение выбранного корпуса клавишей R.
- HUD с резервами всех надетых цветов; выбранный корпус отмечен стрелкой.
- Синхронизация данных HUD с сервера.

## Управление
| Клавиша | Действие |
|---|---|
| R | Переключить выбранный корпус |
| V | Использовать способность корпуса |
| C | Выстрелить энергетическим лучом |
| B | Включить/выключить полёт |
| G | Создать цветную энергоконструкцию (250 энергии) |

## Требования
- Minecraft Java 1.20.1
- Forge 47.x
- Java 17
- Curios API для Forge 1.20.1

Palladium можно установить рядом, но эта версия пока не использует его API напрямую: способности реализованы собственным серверным кодом.

## Сборка
### Автоматическая сборка на GitHub

1. Создай новый пустой репозиторий на GitHub.
2. Загрузи в него содержимое этой папки (включая скрытую папку `.github`).
3. Открой вкладку **Actions** и выбери запуск **Build Minecraft mod**.
4. Дождись зелёной отметки успешной сборки.
5. Открой запуск и скачай артефакт `emotional-spectrum-forge-1.20.1`. Внутри будет `.jar`.

Сборка выполняется на GitHub Actions с Java 17 и Gradle 8.8. При желании можно собрать локально командой `gradle build`; результат будет в `build/libs/emotional_spectrum-0.5.0.jar`.

Установи собранный JAR и Curios API в папку `mods`. Для сервера эти моды также нужны на сервере.

## Статус
Это ранний прототип, не финальный релиз. Энергетический луч использует частицы, а способности — базовые игровые эффекты. Уникальные 3D-конструкции, анимации и прямая интеграция Palladium остаются следующими этапами.


## Версия 0.5 — энергоконструкции
Добавлены девять цветовых визуальных форм: защитная стена, клетка страха, всплеск гнева, спираль надежды, орбиты алчности, купол сострадания, связанные кольца любви, вихрь смерти и сфера жизни. Клавиша G создаёт форму и применяет связанный с цветом игровой эффект. Это первая particle-based версия конструкций: они визуальны и дают эффект, но пока не являются физическими блоками или полноценными 3D-моделями. Также исправлена маршрутизация сетевых действий для полёта и луча.
